# VoiceAssistant-fromScratch

An AI-powered voice assistant built from scratch using Python, JavaScript, and web technologies.

# 🚀 Features
- Voice command recognition
- Natural language processing (using ChatGPT integration)
- Text-to-speech responses
- Custom commands (open apps, play music, search online, etc.)
- Web-based UI for interaction

# 🛠 Technologies Used
- Python
- JavaScript (Vanilla/Node.js)
- HTML/CSS
- ChatGPT API (via OpenAI)
- Web Speech API / SpeechRecognition
- ElectronJS (if it's a desktop app)
- Pyttsx3 or gTTS for TTS
- SpeechRecognition / pyaudio for voice input

# 🧠 How It Works
The assistant listens to user input, processes the query using AI, and gives spoken + textual responses. It can also execute system commands.
